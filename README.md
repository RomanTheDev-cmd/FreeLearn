# Freelearn — открытый локальный сайт

Python 3.10+, без внешних пакетов, аккаунтов и базы данных. Запуск: `python3 app.py`, адрес http://127.0.0.1:8000. Остановка: Ctrl+C. По умолчанию доступ только с этого компьютера. Ничего автоматически не публикуется.

## Материалы

`catalog.json` содержит 10 готовых медитаций по 7:30 и два демонстрационных текстовых материала. У каждой медитации — отдельное описание и шаги из её реальных подсказок, субтитры, текст озвучки и источники. `directions.json` задаёт направления и их тексты.

MP4 остаются в `../Экспорт/Медитация/01–10`; разрешённые файлы перечислены в `media.json`. Сервер отдаёт только эти MP4 по стабильным адресам `/media/meditations/meditation-01.mp4` и далее. Весь каталог экспортов и рабочие материалы не открываются. Файлы видео не дублируются в сайт и не перекодируются. При переносе сайта необходимо сохранить папку Экспорт рядом либо обновить разрешённые пути; запуск проверяет доступность файлов.

Постеры JPG, субтитры VTT, тексты и копии credits лежат в `public/media/meditations/`. Их источники — финальные экспорты; новые ролики/озвучка не создавались. Плеер использует стандартные элементы браузера; MP4 выдаётся порциями с поддержкой Range для перемотки, HEAD не читает содержимое файла. CC включает русские субтитры; под плеером раскрывается текст голосовых подсказок.

## Аккаунты отключены

Регистрация, вход, восстановление и серверный прогресс удалены из приложения. Старые страницы аккаунтов перенаправляются на главную, API возвращает 410. Сервер не открывает и не изменяет прежнюю `data/`, не создаёт новых баз и не использует SQLite. При получении прежней cookie сессии отдаётся команда удалить её; новые cookie и браузерное постоянное хранилище не используются.

Старая база сохранена без чтения/копирования/удаления: это отдельные ранее созданные данные, не рабочая часть сайта. Не возвращать её в общедоступные папки и не отправлять в Git. Решение об удалении или миграции прежних данных требует отдельного поручения. Конфиденциальность и правила обновлены под текущую версию; прежние тексты сохранены в резервной копии исходников в папке проверки.

## Права и приёмка

Музыка каждого видео указана в каталоге, полные условия — в credits рядом с плеером и исходных sidecars экспорта. Исторические технические статусы в credits не переопределяют более поздние решения автора. Голос, Tranquility и баланс приняты Романом; девять других композиций остаются кандидатами. Добавление на локальный сайт по прямому запросу не помечает их автоматически одобренными и не является публикацией в интернете.
